Основи комп’ютерних мереж

Завдання 1. Дослідження мережі

Для визначення мережевих параметрів було виконано команду:

ip a

Результат для активного мережевого інтерфейсу:

11: eth0@if21: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 65535 qdisc noqueue state UP group default
link/ether e2:ed:87:48:77:fa brd ff:ff:ff:ff:ff:ff link-netnsid 0
inet 172.17.0.2/16 brd 172.17.255.255 scope global eth0
valid_lft forever preferred_lft forever

Отримані дані:

- Інтерфейс: eth0
- Тип підключення: Ethernet, віртуальний мережевий інтерфейс Docker
- MAC-адреса: e2:ed:87:48:77:fa
- IP-адреса: 172.17.0.2 — належить до 3-го (мережевого) рівня моделі OSI
- Маска підмережі: /16 або 255.255.0.0 — використовується для визначення мережевої та хостової частин IP-адреси на 3-му рівні OSI
- Gateway: 172.17.0.1
- Broadcast: 172.17.255.255
- Кількість можливих адрес хостів: 65 534

Адреса 172.17.0.2 є локальною IP-адресою контейнера в мережі Docker 172.17.0.0/16.

Завдання 2. Дослідження маршрутизації

Для перегляду таблиці маршрутизації було виконано команду:

ip r

Результат:

default via 172.17.0.1 dev eth0
172.17.0.0/16 dev eth0 proto kernel scope link src 172.17.0.2

Маршрут за замовчуванням проходить через шлюз 172.17.0.1 та інтерфейс eth0.

У записі маршруту вказано proto kernel. Це означає, що маршрут до безпосередньо підключеної мережі 172.17.0.0/16 був створений ядром Linux. kernel у цьому випадку позначає джерело маршруту, а не протокол отримання IP-адреси.

Завдання 3. Знаходження публічної IP-адреси

Для визначення публічної IP-адреси було виконано команду:

curl ifconfig.io

Результат:

195.64.239.74

Публічна IP-адреса: 195.64.239.74

Локальна IP-адреса 172.17.0.2 та публічна IP-адреса 195.64.239.74 відрізняються.

Локальна адреса використовується всередині приватної мережі Docker і не доступна безпосередньо з Інтернету. Під час виходу в Інтернет трафік проходить через Docker, операційну систему та домашній роутер. Для зовнішніх ресурсів з’єднання відображається з публічною IP-адресою. Для перетворення приватних адрес на адресу, яка використовується для доступу до Інтернету, застосовується механізм NAT.
