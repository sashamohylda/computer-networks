## Основи комп'ютерних мереж
---
## 1. Дослідження мережі
Для визначення мережевих параметрів було виконано команду:
```bash
ip a

Результат

11: eth0@if21: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 65535 qdisc noqueue state UP group default
    link/ether e2:ed:87:48:77:fa brd ff:ff:ff:ff:ff:ff link-netnsid 0
    inet 172.17.0.2/16 brd 172.17.255.255 scope global eth0
       valid_lft forever preferred_lft forever

Отримані дані

Параметр	Значення
Інтерфейс	eth0
Тип підключення	Ethernet, віртуальний інтерфейс Docker
MAC-адреса	e2:ed:87:48:77:fa
IP-адреса	172.17.0.2
Рівень OSI для IP	3-й — мережевий
Маска підмережі	/16 (255.255.0.0)
Gateway	172.17.0.1
Broadcast	172.17.255.255
Кількість адрес хостів	65 534

IP-адреса 172.17.0.2 є локальною адресою контейнера в мережі Docker 172.17.0.0/16.

⸻

## 2. Дослідження маршрутизації

Для перегляду таблиці маршрутизації було виконано команду:

ip r

Результат

default via 172.17.0.1 dev eth0
172.17.0.0/16 dev eth0 proto kernel scope link src 172.17.0.2

Маршрут за замовчуванням проходить через шлюз 172.17.0.1 та інтерфейс eth0.

У записі маршруту вказано proto kernel. Це означає, що маршрут до безпосередньо підключеної мережі 172.17.0.0/16 був створений ядром Linux.

Примітка: kernel у цьому випадку позначає джерело маршруту, а не протокол отримання IP-адреси.

⸻

3. Знаходження публічної IP-адреси

Для визначення публічної IP-адреси було виконано команду:

curl ifconfig.io

Результат

195.64.239.74

Публічна IP-адреса: 195.64.239.74

Порівняння адрес

* Локальна IP-адреса: 172.17.0.2
* Публічна IP-адреса: 195.64.239.74
* Адреси не збігаються.

Локальна адреса використовується всередині приватної мережі Docker і не доступна безпосередньо з Інтернету.

Під час виходу в Інтернет трафік проходить через Docker, операційну систему та домашній роутер. Для зовнішніх ресурсів з’єднання відображається з публічною IP-адресою.

Для перетворення приватних адрес на адресу, яка використовується для доступу до Інтернету, застосовується механізм NAT (Network Address Translation).

⸻

Висновок

Під час виконання роботи було досліджено мережевий інтерфейс, таблицю маршрутизації та визначено локальну й публічну IP-адреси. Було встановлено, що локальна та публічна IP-адреси відрізняються через використання приватної мережі та механізму NAT.
